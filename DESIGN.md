# Interface direction

Visual thesis: a quiet graphite measurement surface, blue stacks, precise tabular numbers, generous chart space, and native-feeling controls; an equally legible porcelain light mode.
Content: time controls, linked sessions and grouping controls, one compact total line, an all-model total chart, account quota charts, then full-width model charts, expandable source coverage.
Hourly chart axes use two lines: time above date. Keep complete labels in tooltips, retain timezone offsets for repeated local hours, and let chart geometry determine tick density. Day bins retain their single-line date labels.
Bound each model plot to 120 drawn categories for long ranges by summing adjacent original bins. Disclose the overview grouping and show the complete start/end range in the tooltip. Keep original query totals and evidence; the existing zoom slider uses original bin indices and restores exact chosen granularity at close range. Token and quota plots use the same visible bin edges, while quota observations retain their exact timestamps. Allocate backend buckets once per model, never once per response.
Interaction: brief menu opening and chart updates; persistent appearance through the shared shell; keyboard-accessible chart exploration. No marketing hero or decorative imagery.
Use the shared Data app runtime. For this local app, the top-right controls are only Light, Dark and System appearance choices, directly available and persisted without ChatGPT handoff. Keep the shared theme runtime and chart source inspection; omit local topbar publishing, Ask and editing actions at Sir's request. Hosted surfaces retain their existing chrome. Colors come from adaptive CSS tokens.

The all-model total chart leads, followed by account quota charts and then model charts. Total usage follows the shared effort/composition toggle with the same series colors as model charts; effort shares use the entire selected interval as denominator. Cumulative interval estimates remain a separate stack segment without invented effort or composition; source inspection retains both sources. A collapsed aggregate table follows the total plot, with a separately expandable, paginated original interval table. Account quota follows the total chart as a supporting measurement. Use one fixed 0–100% snapshot dot plot without connecting observations per recorded limit bucket and window length. Its plot edges, hour ticks and zoom match the Token plots; each quota snapshot keeps its original timestamp within the matching bin. Gap shading is optional, off by default and persisted across visits; enabling it shades gaps longer than 15 minutes. Turning it off leaves the base background uniform and retains recovery shading. Keep exact recovery widths and add a separate 8px visibility cue for narrow intervals; disclose that cue width does not encode duration. Highlight the observed interval of a substantial recovery and list both bounds below the plot in a default-collapsed recovery detail; never label a detection timestamp as the actual server reset time. Account scope remains independent of selected sessions. Source inspection retains the scoped original quota snapshots and the preceding observation used as context. Use the shared evidence wrapper and hover marks for the custom interval-aware plot.

Time selection uses one Ant Design date-time range control, with a shortcut/recent sidebar in its popup. Preserve minute precision, explicit IANA timezone interpretation and fixed versus live ranges. On small screens, the popup stays below the app bar and scrolls within the viewport; very narrow layouts stack the calendar and time columns. Relative presets move both bounds, while a custom start may follow now at the end only.

Endpoint editing is direct: click either calendar endpoint or its Start/End button to edit its date and minute; hold for 100 ms to drag its date while retaining its time. Distinct start/end handles remain available when both endpoints share a day. Dragging near a calendar edge turns months after 650 ms. Reject endpoint crossing. All changes remain a draft until the single Apply action; outside click or Escape discards the draft. Disable hover input previews so displayed timestamps match the draft.

History coverage distinguishes response-level usage, quota snapshots and legacy cumulative-only records. Read plain JSONL and immutable Zstandard archives without writing into the source tree. Resolve compressed counterparts before declaring a missing log. Disclose cumulative-only history without inventing response granularity or repeatedly adding cumulative totals.

Legacy estimates retain the observed interval instead of claiming exact consumption times. Deduplicate snapshots, use differences before explicit responses begin, and preserve a confirmed inherited child counter as baseline while retaining a fresh child’s initial measured usage. Same-time cumulative readings use the largest observed counter as a coarse anchor and disclose the lost internal timing. Proportionally apportion integer totals across overlapping query bins without rounding drift. Unknown starts are explicit and belong to their observation bucket. Do not invent model, effort, compaction classification or response counts for legacy intervals.
